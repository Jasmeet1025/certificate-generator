# certificate-generator

Prints ThinkHealth training certificates: **two A5 certificates on each A4 page** (top and bottom, with a light cut
line), all in one PDF, ready to print at actual size. Used by the training dashboard's Fulfillment board.

Each certificate gets four things written on a blank certificate design:

| Field | Where | Font |
|---|---|---|
| Training date (`06/10/2026`) | after "Training Date:" | Open Sans Bold Italic |
| Certificate No. (`FAT-OD/06-10-2026/2077`) | after "Certificate No:" | Open Sans Bold Italic |
| Participant's name | under "This certificate is proudly presented to" | Great Vibes |
| Location ("course conducted at") | on the line under "course conducted at," | Montserrat Bold Italic |

Long names and locations only get a smaller font, so they always stay inside the certificate's border.
Positions, sizes and colours are in `src/layout.ts`.

## The page

`web/` is a one-page tool that runs entirely in the browser — nothing is uploaded anywhere:

1. **Template** — add the certificate PDF exported from Canva once (a filled-in one is fine; the typed names are left
   out). It's kept in this browser only.
2. **Participants** — paste one name per line, rows copied from the register, or open an Excel / CSV file.
3. **Batch** — training location, date and the first serial (numbers count up: `FAT-OD/<date>/<serial>`).
4. Check the band (one column per A4 sheet, top and bottom certificate; a corner notch marks a name printed smaller,
   red means it can't print) and the preview, then **Download PDF** / **Print**, and **Copy rows for register** to
   paste at the end of the master sheet.

```bash
npm install
npm run dev          # http://localhost:5173
npm run build:web    # static site in site/
```

## Use from code

```ts
import { generateCertificates, certificateNumber, printedDate } from "certificate-generator";

const pdf = await generateCertificates({
  background, // the blank certificate design: a one-page PDF (A5 landscape)
  certificates: [
    { name: "Asha Rao", location: "Sample Hotels Pvt Ltd", certNo: certificateNumber("2026-10-06", 2077), date: printedDate("2026-10-06") },
  ],
});
```

## Backgrounds (the certificate designs)

The real designs carry the trainer's signature and the company seal, so **they are never committed** — this repo is
public. Keep them in `private/` (ignored by Git). A background is made from a filled-in template exported from Canva:

```bash
npm install
npm run build
node scripts/make-background.mjs "private/A4 FA Photoedit.pdf" private/backgrounds/cpr-aed-first-aid.pdf
node scripts/sample.mjs private/backgrounds/cpr-aed-first-aid.pdf private/samples/sample.pdf   # made-up people
```

The design picture is copied exactly (same print colours, CMYK); the typed-in text is left out.

## Fonts

Great Vibes, Montserrat and Open Sans are under the SIL Open Font License (`fonts/*-OFL.txt`). They are bundled into
the build (`src/fonts.ts`, generated by `npm run build`), so nothing has to be installed where it runs.
